🛡️ Smart Scam Analyzer

Smart Scam Analyzer is an AI-assisted web application that helps users identify potential scam indicators in suspicious messages, URLs, phone numbers, and UPI IDs.

🎯 Problem & Purpose

Online users frequently receive suspicious messages related to OTPs, KYC, payments, jobs, bank accounts, and unknown links.
It can be difficult for users to identify the warning signs.

The purpose of this project is to provide a quick preliminary risk assessment before users interact with suspicious content.

👥 Target Audience

- Students
- Working professionals
- Online payment/UPI users
- General internet users

✨ Key Features

- 🤖 AI-assisted scam analysis
- 📊 Risk Score and Risk Level
- 🔗 Suspicious URL analysis
- 📱 Phone number detection
- 💳 UPI ID detection
- 🚩 Red Flag identification
- 🛡️ Safety recommendations
- 🌐 Domain information/checks
- 🔌 API integration
- 🔐 No login required
